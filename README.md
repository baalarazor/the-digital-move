# The Digital Move

A premium, responsive business website for The Digital Move, built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Features

- Modern sky-blue SaaS-style design
- Responsive hero, services, industries, about, blog, FAQ, CTA, and contact sections
- Smooth scrolling, animated cards, theme toggle, cookie banner, WhatsApp CTA, and back-to-top button
- SEO metadata, Open Graph, Twitter cards, sitemap, robots, manifest, and schema.org data

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the site.

## Production Build

```bash
npm run build
```

## Deployment

This project is ready for deployment on Vercel.
